## Definition of Done

## Task Completion Criteria
- The code for the task is written and tested.
- The implemented functionality meets the requirements outlined in `currentTask.md`.
- The code adheres to the coding standards defined in `wayOfWorking.md`.
- Relevant documentation in `cline_docs` has been updated.
- The changes have been committed to version control.

## Quality Standards
- **Code Quality:** Code is clean, readable, maintainable, and follows C# best practices.
- **Testing:** The implemented tools and features have been tested, ideally using the MCP Inspector.
- **Documentation:** Documentation is accurate and reflects the current state of the project.
- **Functionality:** The implemented features work as expected and handle edge cases gracefully.
- **Performance:** The implementation is reasonably performant, with plans for optimization if needed.
- **Security:** Sensitive information is handled securely (e.g., using environment variables).
